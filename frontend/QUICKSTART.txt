❓ TROUBLESHOOTING:

   Port 5173 in use?
   → npm run dev -- --port 5174

   Backend not connecting?
   → Check .env: VITE_API_BASE_URL=http://localhost:5000/api
   → Check backend is running: curl http://localhost:5000/health

   Login fails?
   → Check backend logs in backend folder
   → Try a different browser / incognito window

   QP generation takes too long?
   → This is normal! RAG calls Groq API (10-30 seconds)
   → Don't close the page during generation
