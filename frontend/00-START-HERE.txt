TROUBLESHOOTING QUICK REFERENCE:

   Issue: Frontend can't connect to backend
   Fix: Check .env has VITE_API_BASE_URL=http://localhost:5000/api

   Issue: Login fails
   Fix: Ensure backend is running (npm run dev in backend folder)

   Issue: Port already in use
   Fix: npm run dev -- --port 5174 (use different port)

   Issue: QP generation is slow
   Fix: This is normal! Groq API takes 10-30 seconds

   Issue: Blank page after login
   Fix: Check browser console (F12) for errors
        Make sure subjects are in database (run npm run seed in backend)
